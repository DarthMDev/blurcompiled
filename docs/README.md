# Contributor guide

Start with [build instructions](BUILD_GAME.md). These are the only current guides:

| Guide | Read it when |
| --- | --- |
| [Build the game](BUILD_GAME.md) | You have your own Xbox copy and want to generate/compile the host |
| [Development](DEVELOPMENT.md) | You want source layout, support builds and test commands |
| [Graphics](GRAPHICS.md) | You want to investigate the dark/red rendering or Plume integration |
| [Roadmap](ROADMAP.md) | You want milestones and work to pick up |

[Contribution guidelines](../CONTRIBUTING.md) explain evidence and PR expectations.
Dated session-by-session engineering records are retained in Git history rather
than mixed into the current contributor documentation.
